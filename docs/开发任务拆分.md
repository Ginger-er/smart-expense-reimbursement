# 智能差旅报销系统 —— 开发任务拆分

> 按 7 个里程碑拆分为 8 周可执行任务，每个任务有明确的输入、输出、验收标准。

---

## M1：基础搭建（第1周）

### 任务 1.1：项目初始化
- **时间**：0.5天
- **输入**：技术选型文档
- **产出**：
  - Spring Boot 项目骨架（Maven，Java 17，Spring Boot 3.2）
  - Vue 3 项目骨架（Vite，TypeScript）
- **验收**：前后端均能 `npm run dev` / `mvn spring-boot:run` 启动

### 任务 1.2：数据库搭建
- **时间**：0.5天
- **输入**：数据库设计文档
- **产出**：
  - `init.sql`（6张表：sys_user, sys_dept, trip, invoice, reimbursement, approval_record）
  - MyBatis-Plus 代码生成器生成 Entity + Mapper
- **验收**：MySQL 中建表成功，所有 Mapper 能执行基础 CRUD

### 任务 1.3：基础配置
- **时间**：1天
- **输入**：技术架构文档
- **产出**：
  - application.yml（MySQL, Redis, MinIO, Sa-Token, Camunda 配置）
  - 跨域配置、Swagger 配置、MyBatis-Plus 分页插件
  - 统一返回类（Result, PageResult）
  - 全局异常处理
- **验收**：Swagger 页面可访问，`/api/test` 返回统一格式 JSON

### 任务 1.4：用户认证
- **时间**：1天
- **输入**：RBAC 权限设计
- **产出**：
  - 登录/登出接口（Sa-Token）
  - 密码 BCrypt 加密
  - 前端登录页 + token 存储 + 路由守卫
- **验收**：登录→获取token→访问受保护接口→登出→token失效，完整流程跑通

### 任务 1.5：基础 CRUD 接口
- **时间**：2天
- **输入**：数据表设计
- **产出**：
  - 用户管理 CRUD（分页、搜索、启用/禁用）
  - 部门管理 CRUD（树形结构）
  - 出差申请 CRUD
- **验收**：Swagger 文档完整，每个接口可调通

## M2：发票识别（第2周）

### 任务 2.1：MinIO 文件存储集成
- **时间**：0.5天
- **输入**：MinIO 配置
- **产出**：
  - MinioConfig 配置类
  - FileUtil 工具类（上传、获取签名URL、删除）
- **验收**：上传图片→返回URL→浏览器可访问签名URL

### 任务 2.2：发票上传接口
- **时间**：1天
- **输入**：文件存储集成
- **产出**：
  - POST /invoice/upload（接收文件+出差ID，返回识别结果）
  - 文件类型校验（JPG/PNG/PDF）
  - 文件大小限制（10MB）
  - 前端拖拽上传组件
- **验收**：前端拖拽/点击上传→后端存储到MinIO→返回文件URL

### 任务 2.3：百度 OCR 集成
- **时间**：1.5天
- **输入**：发票图片
- **产出**：
  - OcrService（封装百度API调用）
  - 发票字段提取（发票号码、代码、金额、税额、日期、类型、销售方、购买方）
  - 识别结果保存到 invoice.ocr_json
- **验收**：上传真实发票照片→OCR返回结构化数据→数据库中可查

### 任务 2.4：数据校验层
- **时间**：1天
- **输入**：OCR识别结果
- **产出**：
  - 金额一致性校验（金额 = 明细求和）
  - 日期有效性校验（开票日期 ≤ 今天）
  - 发票代码校验位验证
  - 重复报销检测（同发票号+代码已报销则拦截）
  - 关联合理性校验（开票日期在出差日期范围内）
- **验收**：每种校验规则都能触发，失败时返回明确错误信息

### 任务 2.5：前端发票管理页
- **时间**：1天
- **输入**：发票上传/确认接口
- **产出**：
  - 发票上传页（拖拽上传 + 识别结果展示 + 确认/修正）
  - 发票列表页（时间轴、类型筛选、批量选择）
- **验收**：上传→识别→校验→确认→关联出差，全流程前端可用

## M3：报销审批（第3-4周）

### 任务 3.1：报销单生成
- **时间**：1天
- **输入**：已关联的发票
- **产出**：
  - POST /reimbursement/create（从 trip 归集发票→计算总金额→生成报销单）
  - 报销单号生成器（RB + 日期 + 序号）
- **验收**：选择出差申请→自动归集发票→生成报销单

### 任务 3.2：Camunda 审批流集成
- **时间**：2天（本周核心难点）
- **输入**：审批流程设计（3级：直属领导→部门经理→财务总监）
- **产出**：
  - BPMN 流程定义文件（reimbursement-approval.bpmn）
  - 条件分支网关（金额<1000：1级，1000-5000：2级，≥5000：3级）
  - 流程启动/推进/查询 Service
  - Camunda 配置类
- **验收**：启动流程→Camunda 创建实例→人工推进节点→流程结束，BPMN 图正确执行

### 任务 3.3：审批接口
- **时间**：1天
- **输入**：Camunda 流程引擎
- **产出**：
  - POST /reimbursement/submit（提交审批，启动流程）
  - POST /reimbursement/approve（通过/驳回/转办，推进节点）
  - 审批记录写入 approval_record
  - 驳回时状态回退 + 原因记录
- **验收**：提交→逐级审批→通过/驳回→状态正确流转→审批记录完整

### 任务 3.4：前端审批中心
- **时间**：1天
- **输入**：审批接口
- **产出**：
  - 审批中心列表（待审批/已审批 tab）
  - 报销单详情页（左右分栏：发票信息+审批流时间轴）
  - 审批操作组件（通过/驳回/转办 + 意见输入）
- **验收**：审批人看到待审批列表→点击详情→查看发票→通过/驳回→状态即时更新

### 任务 3.5：出差申请完善
- **时间**：1天
- **输入**：出差 CRUD
- **产出**：
  - 出差申请表单（基本信息→行程→预算）
  - 出差列表页
  - 状态流转（草稿→已提交→审批中→已通过）
- **验收**：完整出差申请流程可用

## M4：异常预警（第5周）

### 任务 4.1：预警规则引擎
- **时间**：1.5天
- **输入**：5条预警规则
- **产出**：
  - AbnormalRuleService（策略模式，每条规则一个实现类）
  - A001 金额突增（同员工同类型本月>上月150%）
  - A002 限额擦边（单张>标准限额90%）
  - A003 重复发票（同发票号+代码重复）
  - A004 日期异常（开票日期不在出差范围）
  - A005 高频报销（7天内>3次）
- **验收**：每规则单独测试，命中时返回规则编码+详情

### 任务 4.2：定时任务
- **时间**：0.5天
- **输入**：预警规则引擎 + XXL-Job
- **产出**：
  - XXL-Job 执行器配置
  - expense-abnormal-scan 任务（每天9:00，扫描昨日报销→逐条匹配规则→写入abnormal_record）
- **验收**：XXL-Job 调度中心可看到任务→定时触发→异常记录写入数据库

### 任务 4.3：DeepSeek AI 集成
- **时间**：1天
- **输入**：异常记录
- **产出**：
  - AiService（统一封装，支持降级/缓存/限流）
  - 发票摘要生成（上传确认后调用）
  - 预警摘要生成（异常扫描后调用）
  - 提示词模板管理（resources/prompts/）
- **验收**：异常被规则命中→生成AI摘要→摘要存入数据库，文案专业可用

### 任务 4.4：前端异常看板
- **时间**：1天
- **输入**：异常预警接口
- **产出**：
  - 异常预警看板页（统计卡片 + 异常列表 + 趋势图）
  - 异常卡片（风险等级色条、AI摘要引用块）
  - 操作：查看详情/标记已处理/立即驳回
- **验收**：看板展示异常数据→筛选/操作可用

## 风险提示

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| Camunda 学习曲线陡 | 高 | 延迟 M3 | 提前看文档，先用简单流程跑通再复杂化 |
| 百度OCR识别率不达标 | 中 | M2 受阻 | 备份方案：腾讯云OCR / 允许手动输入 |
| DeepSeek API 不稳定 | 中 | M4 AI摘要不可用 | 降级方案：模板文案替换 |
| 时间不够 | 中 | 整体延期 | 砍优先级低的功能，先保核心3模块 |

- **M1**：项目能跑吗？CRUD能调通吗？Swagger能看到吗？
- **M2**：发票上传了OCR能识别吗？校验5条都覆盖了吗？
- **M3**：Camunda流程跑通了吗？3级审批能正确路由吗？
- **M4**：定时任务触发了异常能生成吗？AI摘要文案像人写的吗？
- **M5**：页面长什么样？交互流畅吗？
- **M6**：主流程跑一遍，有Bug吗？
- **M7**：外网能访问吗？Docker能一键启动吗？
